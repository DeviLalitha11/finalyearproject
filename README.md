## Project Description
This project focuses on early prediction of chronic diseases such as
Diabetes, Heart Disease, Hypertension, Thyroid, and Kidney disorders
using Machine Learning and Deep Learning techniques.

The system analyzes personal health data and provides:
- Disease risk prediction
- Explainable AI results using SHAP
- Personalized health recommendations

## Technologies Used
- Python
- Scikit-learn
- TensorFlow
- SHAP
- Streamlit

- src/ → Core logic
- app/ → User interface
